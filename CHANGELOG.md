# Changelog

## 0.1.0

The first release.

- **Connect:** shows the bridge, whether the Tracy viewer is attached, and live tracks.
- **Place setup:** inserts or updates the Tracy module, allows HTTP requests, and points
  the place at the bridge. Every change can be undone.
- **Capture:** one-click MicroProfiler captures during playtests (needs LibMP).
- **Settings:** global and per-place, plus a help window.
- **Bundled module:** Tracy-Luau 0.5.0.
